# 推し活ノート

チケットの入金期限・抽選の締切を忘れないためのiPhone向けアプリ（PWA）。推し活の出費と月の予算も記録できる。

- 無料・アカウント不要・サーバー不要
- データはそのiPhoneの中（localStorage）だけに保存。外には送らない
- 「カレンダーにアラームを入れる」でiPhoneのカレンダーに予定を追加（時刻あり：前日と3時間前／時刻なし：前日9時と当日9時に通知）

## できること

- 期限の登録：入金期限・抽選の締切・当落発表・公演・発売/予約締切・その他
- 期限が近い順に表示。期限切れ・今日まで・3日以内は色で分かる
- 「入金した」を押すと、完了にして出費にも自動で記録
- 「当選した！」を押すと、そのまま入金期限の登録画面へ
- スクショ・投稿文から読み取り：日付・時刻・値段・販売場所・ハッシュタグを抜き出して、確認してからまとめて登録（無料OCR／貼り付け）
- 推しごとのハッシュタグと検索：「#ちいかわ」で次の発売日・過去の予定・使ったお金をまとめて表示
- これから必要なお金：「○月末までに累計いくら」を表示
- 画面の色（8色）・明るさ・背景画像（自分で選んだ画像）
- 出費の記録（チケット・グッズ・交通費・宿泊・FC/配信・飲食・その他）
- 月の予算と、何に・どの推しにいくら使ったかの集計
- バックアップ（JSONファイル）と復元

## ファイル

全部同じ階層に置く（GitHubのWebアップロードでフォルダが消えても動くように）。

| ファイル | 中身 |
|---|---|
| index.html | 画面の骨組み |
| style.css | 見た目（ダークモード対応） |
| calc.js | 計算（日付・残り日数・集計・カレンダー用ファイル） |
| app.js | 画面の動き・保存 |
| ocr.js | スクショの文字読み取り（Tesseract.js、端末内で処理） |
| sw.js | オフラインで開けるようにする |
| manifest.webmanifest / icon-*.png | ホーム画面に追加したときの名前とアイコン |
| calc.test.js / test.html | 計算のテスト（test.html をブラウザで開くと実行） |
